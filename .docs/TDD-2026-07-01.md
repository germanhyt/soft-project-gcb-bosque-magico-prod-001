## Reglas de negocio → config (referencia)

| Concepto | Claves API |
|----------|------------|
| Show incluidos | `shows.ninos_incluidos` (default 20) |
| Show extra S/ | `shows.precio_nino_extra` (default 15) |
| Tope evento | `ninos.maximo_permitido` (default 30) |
| Extra servicios S/ | `extras.precio_nino_extra` (default 10) |
| Catering mínimo | producto `cantidadMinima` + config `catering.minimo_unidades` |

Rango show extra en runtime: del niño **`ninos_incluidos + 1`** al **`ninos.maximo_permitido`**.
